TITLE: Palabras con números
TAGS: Ejercicio


Se cuenta con el archivo de registros `PALABRAS.dat`, el cual contiene palabras de hasta 15 caracteres. Estas palabras pueden tener un número entero incrustado en alguna parte. Es posible que varias palabras compartan el mismo número o que algunas no contengan ningún número.

Un ejemplo de este archivo podría ser: PALABRAS = {“comp''12''utadora”, “ce''3''lular”, “''4''ventana”, “prehistoria”, “mochila''2''”, “baldos''4''a”, “distorsión”, “''3''arbusto”, “d''5''eportista”, “dicotom''531''ía”}.

Se solicita mostrar las palabras del archivo en orden, de acuerdo con el número que contienen. En caso de que varias palabras compartan el mismo número, estas deben mostrarse en el orden inverso al que aparecieron en el archivo. Las palabras que no tienen ningún número deben omitirse.

Según el ejemplo proporcionado, la salida del programa debería ser:

```
2: mochila
3: arbusto, celular
4: baldosa, ventana
5: deportista
12: computadora
531: dicotomía
```
