TITLE: Letras
TAGS: Ejercicio


Se dispone del archivo `PALABRAS.dat` cuyo contenido es una lista de palabras de hasta 15 caracteres. Se solicita procesar estas palabras para generar tantos archivos nuevos como letras diferentes existan en el conjunto de palabras. En cada archivo se deben incluir las palabras que contienen la letra correspondiente. 

Las palabras grabadas en los archivos deben estar en minúscula, a excepción de la letra que la clasifica, que debe estar en mayúscula.

Por ejemplo, si el contenido del archivo fuese: PALABRAS = {casa, coche, caballo, cascabel, camion}, el programa debe generar archivos como: `C.dat`, `A.dat`, `S.dat`, `E.dat` y `O.dat`, etc., cada uno conteniendo todas las palabras que incluyen esa letra. Las palabras en cada archivo generado deben aparecer en el orden inverso al que aparecen en el archivo original. 

Según el ejemplo proporcionado, el programa debe generar estos archivos con el siguiente contenido cada uno:

```
+--------+--------+--------+-------+-----+--------+--------+--------+------+------+------+
|C.dat   |A.dat   |S.dat   |O.dat  |H.dat|E.dat   |B.dat   |L.dat   |M.dat |I.dat |N.dat |
+--------+--------+--------+-------+-----+--------+--------+--------+------+------+------+
|Camion  |cAmion  |caScabel|camiOn |cocHe|cascabEl|cascaBEl|cascabeL|caMion|camIon|camioN|
|CasCabel|cAscAbel|caSa    |caballO|     |cochE   |caBallo |cabaLLo |      |      |      |
|Caballo |cAbAllo |        |cOche  |     |        |        |        |      |      |      |
|CoChe   |cAsA    |        |       |     |        |        |        |      |      |      |
|Casa    |        |        |       |     |        |        |        |      |      |      |
+--------+--------+--------+-------+-----+--------+--------+--------+------+------+------+
```
